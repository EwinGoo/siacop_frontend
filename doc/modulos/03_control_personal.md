# Modulo frontend: Control personal

## Que hace

Agrupa pantallas administrativas que alimentan los justificativos y procesos de asistencia.

## Submodulos

- Feriados y asuetos.
- Tipos de permiso.
- Permisos.
- Boletas de comision.
- Declaratoria en comision.
- Asignaciones administrativas.
- Reporte de vacaciones.

## Acciones comunes

- Listar.
- Buscar y filtrar.
- Crear.
- Editar.
- Eliminar/anular cuando aplica.
- Aprobar.
- Observar.
- Generar PDF.
- Ver detalle.

## Endpoints base

- `API_ROUTES.CONTROL_PERSONAL`
- `API_ROUTES.ASIGNACION_ADMINISTRATIVO`
- `API_ROUTES.REPORTES`

## Importancia para el proyecto

Estos modulos complementarios justifican ausencias, permisos, comisiones, vacaciones y condiciones especiales usadas por el motor de asistencia.
