# Modulo frontend: Guardias de seguridad

## Que hace

Permite administrar bloques, grupos, miembros, turnos, programacion semanal, asignaciones y reemplazos.

## Vistas principales

- Bloques.
- Grupos.
- Miembros por grupo.
- Horario semanal.
- Configuracion de rotacion.
- Asignaciones manuales.

## Endpoint base

```text
API_ROUTES.GUARDIAS
```

## Relacion con asistencia

La programacion de guardias altera horarios esperados y permite calcular asistencia en turnos especiales.
