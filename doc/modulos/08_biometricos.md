# Modulo frontend: Biometricos

## Que hace

Administra dispositivos biometricos y operaciones ZKTeco disponibles desde la SPA.

## Vistas y acciones

- Listar dispositivos.
- Registrar/editar dispositivo.
- Probar conexion.
- Ver informacion del equipo.
- Gestionar sesion ZKTeco.
- Consultar usuarios del dispositivo cuando aplica.

## Endpoints base

- `API_ROUTES.ADMINISTRADOR + /biometrico`
- `API_ROUTES.ADMINISTRADOR + /zkteco`

## Recomendacion

Depurar componentes de prueba o administracion no usados antes de produccion y quitar `console.log` activos.
