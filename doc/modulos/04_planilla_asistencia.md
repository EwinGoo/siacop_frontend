# Modulo frontend: Planilla de asistencia

## Que hace

Permite operar el motor de asistencia desde React: importar marcaciones, crear procesos, ejecutar calculos y consultar resultados.

## Vistas principales

- Importacion de marcaciones.
- Resumen de importaciones.
- Procesos mensuales.
- Ejecucion de procesos.
- Resultados diarios.
- Resultados mensuales.
- Detalle por persona.

## Endpoint base

```text
API_ROUTES.PLANILLA_ASISTENCIA
```

## Datos que muestra

- Marcaciones crudas.
- Marcaciones normalizadas.
- Procesos por gestion/mes.
- Resultado diario.
- Resultado mensual.
- Estados y observaciones.
