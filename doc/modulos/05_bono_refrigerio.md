# Modulo frontend: Bono refrigerio

## Que hace

Muestra el consolidado de bono refrigerio por proceso mensual y permite generar reportes PDF.

## Datos que muestra

- Persona.
- Dias validos.
- Dias excluidos.
- Dias no validos.
- Detalle diario.
- Totales para reporte.

## Endpoint base

```text
API_ROUTES.PLANILLA_ASISTENCIA
```

## Acciones

- Consultar resumen.
- Ver detalle por persona.
- Filtrar resultados.
- Generar reporte general PDF.
